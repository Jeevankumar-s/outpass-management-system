# 🎓 Outpass Management System

An efficient digital solution to manage student outpasses, replacing traditional paper-based processes with a modern web-based application.

[🔗 View Project on GitHub](https://github.com/Jeevankumar-s/outpass-management-system)

## 🚀 Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** SQLite
- **Others:** Nodemailer, PDFKit

---

## 📌 Features

- 📝 Student Outpass Request Portal
- ✅ Admin/Staff Approval Workflow
- 📧 Automated Email Notifications via Nodemailer
- 📄 PDF Generation of Approved Outpasses using PDFKit
- 🗂️ Student-wise Record Management
- 🔒 Basic Authentication/Validation
